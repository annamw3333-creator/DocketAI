Adds a Docket website chat bubble to every public page. A Docket desk account is required. Hosts are allowlisted; iframe is sandboxed.

== Description ==

Docket Assistant is a **connector for the Docket desk service**. It does not generate replies inside WordPress. After you paste your Docket URL and bot ID, visitors see a chat bubble. Opening it loads your published assistant in a **sandboxed iframe** from your Docket desk.

**This plugin calls a third-party service (SaaS / your self-hosted desk).**

* Service: the Docket URL you enter in Settings → Docket Assistant (must be on the allowlist).
* What is sent: visitor chat messages, typed in the widget, to that Docket desk so the assistant can reply.
* Account: you must have a Docket account and a published assistant. The plugin does nothing until those two fields are saved.

**Allowlisted service hosts (HTTPS required unless WP_DEBUG + localhost):**

* docket.app and subdomains
* docketdesk.com and subdomains (www, app, desk)
* localhost / 127.0.0.1 (local desk only when WP_DEBUG)

Userinfo in URLs and non-standard ports are rejected. Filter `docket_assistant_allowed_hosts` to extend the list for private deploys.

**Content Security Policy (CSP)**

If your site sends a CSP header, allow the desk origin:

`Content-Security-Policy: frame-src 'self' https://desk.docket.app https://*.docket.app https://*.docketdesk.com;`

The launcher sets `sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox"` on the iframe and `referrerpolicy="no-referrer"`.

Settings also store optional Slack/email alert targets and show an embed snippet for custom themes. Pair with the companion **desk/** mystery-shop API in this deliverable for scorecards, bake-offs, and regression CI.

== Installation ==

1. Upload the `wordpress-plugin` folder (or zip) via Plugins → Add Plugin → Upload.
2. Activate **Docket Assistant**.
3. Open Settings → Docket Assistant.
4. Paste your **Docket URL** and **Bot ID** from the desk → Add to site.
5. Optional: alert webhook / email for score-drop notifications.
6. Save. The bubble appears on every public page.

== Frequently Asked Questions ==

= Does this work without a Docket account? =

No. Generate a desk first, then paste the URL and bot ID here.

= Where do visitor messages go? =

To the Docket URL you configure. Replies are generated by that service. Do not install unless you trust that desk.

= Threat model — what can go wrong? =

* A malicious `service_url` could point the iframe at an attacker site. Mitigation: host allowlist, HTTPS, reject userinfo/odd ports, sandboxed iframe, local-only launcher JS.
* XSS in settings: Settings API + sanitize/escape; capability `manage_options`.
* Data exfil via widget: treat the desk as trusted SaaS; CSP frame-src limits where iframes can load.

= Does the plugin load remote JavaScript from Docket? =

No. The launcher is local. The chat panel is an iframe of your Docket widget.

= How do I remove it? =

Deactivate and delete. Uninstall removes saved settings.
